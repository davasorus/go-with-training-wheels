# Project 5: Gin Web Service
A RESTful API built with the Gin framework that provides endpoints for managing a collection of records (albums).

## Endpoints
- `GET /albums`: Retrieve all albums from the database.
- `GET /albums/:id`: Get details of a specific album by its ID.
- `POST /albums`: Add a new album to the system.

## Getting Started
Run the server using:
```bash
go run main.go
```
The service will run on `localhost:8080`.
